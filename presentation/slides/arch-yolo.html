PIPELINE A — DETECTOR-DRIVEN

YOLO26 + ByteTrack

Every frame is re-examined. Identity is inferred, not assumed.

YOLO26

Detector. Finds every car, truck, aircraft or bird in the frame — from scratch, every pass.

ByteTrack

Kalman motion + Hungarian matching. Gives each detection an identity, and keeps it through the frames the detector is unsure about.

Target memory

A layout fingerprint of the picked target. Recognises it again after a gap, and refuses look-alikes that lead by too little.

CSRT follower

Correlation tracker. Carries the box between detection passes — the fast, cheap part of the loop.

OUTPUT

box · track ID · position & speed · motion trail · prediction arrow
