PIPELINE B — TEMPLATE-DRIVEN

SiamMask

One template, set once. Nothing else in the frame is ever examined.

Template, at pick time

The box you draw becomes a fixed appearance template — a ResNet-50 embedding of the target, taken once.

Local search window

Each frame, only a 255px window around where the target was last seen is searched — never the whole image.

Siamese match + mask

The window position that best matches the template wins, and a pixel mask of the object is returned with it.

OUTPUT

pixel mask · real outline · box

No detector, no identity, no memory — nothing here knows what a car is
